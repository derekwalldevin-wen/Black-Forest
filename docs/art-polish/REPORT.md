| 发现 | 已接入的修改 |

| 事件插画侵入遗物栏，出现“尚无遗物”浮在插画上 | 画窗调整为 944×624，从 y=258 开始；完整留出遗物栏，比例更接近生成的横向原图 |

## 素材和来源

内置 image_gen 生成两张透明图集；不是从第三方网站下载。新增 **32 个运行 PNG：14 遗物 + 2 妖契 + 16 战斗图标**。每个文件 256×256，主体最长边 224，四周至少 16 像素透明安全边距。源图完整保留，切分按连通轮廓归属，避免上扬的灵韵图形被网格边界截断。

运行图标合计 **2.60 MiB**，从初版 384 像素的 5.73 MiB 减少约 55%；最大展示是遗物奖励 248 逻辑像素，原始图集不随运行包加载。数字、中文名称、规则与点击区域仍由游戏绘制。

- 原图：`assets/ui/relic-icons-source-v1.png`、`assets/ui/tactical-icons-source-v1.png`。
- 提示词：`RELIC-PROMPT.json`、`TACTICAL-PROMPT.json`。
- 切分来源、尺寸、透明信息和 SHA256：`ASSETS.json`。
- 制作脚本：`tools/prepare-icon-art.js`。
- 注册与公用说明：`src/core/icon-art.js`，BootScene 实际加载全部 32 图。
- 接入：`ui.js`、`CombatScene.js`、`RewardScene.js`、`EventScene.js`；打包沿用运行素材白名单，排除 source 图集。
