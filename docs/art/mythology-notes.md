# 立绘采用的形态与原典核对

本轮按游戏交接里的造型方向制作，不把所有游戏化细节都标成《山海经》原典。

- 帝江：囊形、无面目、六足四翼。与原典核心形态一致，必须能逐个数清。[《山海经·西山经》](https://zh.wikisource.org/wiki/山海經/西山經)
- 穷奇：采用有翼虎形。[《山海经·海内北经》](https://zh.wikisource.org/wiki/山海經/海內北經)提供此形态；交接中的引文混合了另一种描述，不能作为同一段原文。
- 相柳：保留交接要求的九个蛇头、青色蛇身，作为本游戏的视觉改编。原典描述为九首人面，此处不声称纯蛇头就是原典造型。[《山海经·海外北经》](https://zh.wikisource.org/wiki/山海經/海外北經)
- 祸斗：交接选定的是独角羊形火兽；本轮保留这项游戏设计，不沿用其“状如人而一足”引文作原典依据。
- 饕餮：采用交接中的巨口兽首和短前肢，作为青铜饕餮意象的游戏化设计。
- 白泽：采用交接中的智者狮兽、额外角与克制的人面意象，不把该设定整体标为《山海经》直接记载。
