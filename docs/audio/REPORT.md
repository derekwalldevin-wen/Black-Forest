# 音效接入 · 2026-10-12

14 个原创合成音效已进入正式游戏，包括界面确认、选牌、出牌、资源不足、敌人挥击、命中、盾牌吸收伤害、获得格挡、我方掉血、回血、结束回合、胜利、战败和结局。波形由 `tools/generate-sfx.js` 确定性生成，没有引用外部录音或样本；来源、响度、时长与哈希见 `ASSETS.json`。

实际音频文件为 24 kHz、16 bit、单声道 WAV，共 368302 字节，最长 1.9 秒。声音只负责反馈，不改变战斗规则与结算时机。

## 触发与控制

- 只有通过费用及状态校验的出牌才播放提交声；资源不足播放拒绝声。
- 敌人攻击动作开始播放挥击声，实际结算时按格挡吸收量和掉血量分别播放盾声、受伤声。完全格挡不会播放掉血声，部分格挡同时反馈两种结果。
- 获得格挡与盾牌吸收伤害使用不同声音。实际恢复生命才播放回血声，满血无效治疗保持安静。
- 减少动态模式仍保留声音反馈。首次真实点击或按键解锁浏览器音频；未解锁的事件直接略过，之后不会补播。
- 默认音量 55%。行囊 → 声音设置提供静音、音量调整和格挡/回血试听；保存于独立的 `black-forest-audio-settings`，不改征途存档。
- 切到后台、暂停或离开场景会清理正在播放的声音；最多 8 个并发声部，重复短声限频，播放完成销毁声音对象。
- `?sound=off` 可临时关闭音效做对比，不覆盖保存的设置。
