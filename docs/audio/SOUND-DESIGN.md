# 黑森林：完整声音设计与分期实施

设计日期：2026-10-14。本文是待实施方案，不代表新素材已生成或上线。

## 当前实况

已核对 audio.js、audio-assets.js、CombatScene、StoryScene、JournalScene 与 hero-fx.js。
当前只有 14 个原创程序合成的短音效：界面、选牌、出牌、拒绝、挥击、命中、格挡、获得护盾、掉血、治疗、回合、胜利、失败、结局。
没有持续配乐、章节环境循环、敌人音色分类、专属招式声或独立剧情提示。剧情主要沿用公共按钮声。
现有音量设置仅一组；并发上限 8，超限淘汰最早声音；暂停与后台会清理声音。这些规则适用于短音效，不适合直接承载音乐。

## 声音身份

主角是提灯旅人：以灯芯轻燃、玻璃共振、纸张、衣料和克制的金属音构成身份。招式有力量，但保留温暖的人性。
哥特境域以低弦、木质打击、风与枝叶为主；东方境域以拨弦、箫息、青铜和石质共振为主。两个世界共用一个短小的“提灯”旋律动机，改变配器与和声，避免像两部不相干的游戏。
母亲青禾的回声使用同一动机的残缺形态。结局将它展开；不依赖持续低吼、尖叫或无意义耳语制造恐怖。

初版先完成完整循环曲和淡入淡出；只有拿到严格同长度、同拍点的分轨后，才做节奏层叠加。不要把不同生成结果当作可同步的音乐分轨。

## 环境与剧情

六个章节各一条低存在感环境底：森林风与枝叶、沼泽水泡与远处虫声、根系低鸣与土壤摩擦、青丘风铃与草叶、灰烬风与余火、门扉低风与青铜共振。
环境循环 30–60 秒；少量离散细节随机间隔播放，不能每隔固定秒数重复同一声。底噪不盖住文字阅读，沼泽和灰烬避免连续刺耳高频。

剧情补充六类短声：翻开家书、翻页、点灯、青禾回声提示、门扉开启、选择落定。
按具体剧情事件标记触发，不能每次 render() 都播放。快速翻页、略过和日记回看不积压声音；不在每个汉字出现时发声。两项选择使用相同中性确认声，避免暗示正确答案。
本轮不做全剧情配音；先把文本节奏与音乐做好。青禾可用音乐与空间尾音表达，不添加没有剧本依据的台词或呼吸。

## 战斗声音：动作与结算分开

| 事件 | 声音设计 | 权威触发条件 |
| --- | --- | --- |
| 主角普通斩击 | 衣料与锐利短风声，命中时木金属混合瞬态 | 合法提交动作；实际伤害结算另触发命中 |
| 重击 | 更低、更厚的起音和尾音 | 明确的招式配置；不把所有稀有牌等同重击 |
| 连击 | 每次挥击和每次落点区分，末击略重 | 实际每段结算，不另造伤害次数 |
| 符箓 | 纸张展开、朱砂摩擦、短青铜共鸣 | 符箓动作开始与生效分别触发 |
| 共鸣/回响 | 相同音色的短回应，克制抬升 | 对应机制真实发生，不以特效数量推断 |
| 获得格挡 | 向内聚合的柔和蓝色玻璃感 | 实际增加格挡 |
| 完全格挡 | 清脆盾面共振，短而明确 | 吸收量大于 0、掉血为 0；无受伤声 |
| 部分格挡 | 盾声在前，较低受伤声叠加 | 吸收量、实际掉血均大于 0 |
| 护盾耗尽 | 一次短裂纹尾音 | 受击消耗前有盾、之后归零；不能因回合清盾触发 |
| 受到伤害 | 身体/衣料冲击与短低音 | 实际掉血大于 0；不使用每击尖叫 |
| 治疗 | 温暖上行亮音、灯光扩散感 | 实际回血大于 0；满血无效治疗保持安静 |
| 持续状态 | 毒用细微腐蚀、火用短燃烧、流血用低短脉冲 | 状态真实结算；同一结算批次限频 |

敌人先按 4 组音色制作：兽类撕咬/爪击、重量型冲撞/践踏、巫术施法、异兽青铜与风息。16 个敌人通过配置映射到这些组；两个 BOSS 再加专属起手与死亡声。不要首轮给每个敌人录全套，也不要简单变调到所有敌人听起来相同。
常用挥击、命中、格挡、掉血每类至少 3 个变体，禁止连续重复同一个变体；少量音高浮动只是补充。最终素材数量以映射表盘点为准。

## 界面与混音

保留现有清晰的选牌、提交、拒绝区别；补充抽牌、弃牌/耗尽、奖励入袋、遗物获得、铸坊确认、妖契订立、升契。批量抽牌只保留少量纸声，不能一口气叠满声道。悬停和资源数字刷新保持安静。

总音量下分音乐、环境、音效三组；界面和剧情短声先归音效组。旧 volume/muted 迁移为总音量/静音，保留旧用户偏好，禁止升级后突然恢复声音。
优先级：实际受击与护盾结果 > 招式提示 > 剧情关键提示 > 普通界面。音乐与环境有独立声部，不参与短声的“淘汰最老”规则；超限先丢低优先级纸声和装饰音。
初始混音建议：以命中声音为基准，音乐低约 12–18 dB、环境低约 20–26 dB，随后以素材实听修正，不能只按文件峰值定音量。关键命中时音乐短暂降低约 3 dB，不让每次点击都触发音量抽动。
左右站位可用轻微声像；所有重要信息必须在单声道手机扬声器仍可辨识。不做持续心跳警报；低血量仅在首次跨入阈值时提示，恢复后才允许再次触发。

## 接入边界

新增常驻音频管理层负责音乐/环境，保留短声 SFX 接口并逐步扩展变体、优先级与事件参数。所有场景切换通过同一入口请求声音状态，避免重复启动循环。
背景切换音乐建议淡化 0.8–1.5 秒；剧情与战斗快速往返不能反复从头重播。打开行囊降低音乐音量，返回恢复；进入后台停止可听输出，恢复后只恢复当前场景循环，绝不补播历史短声。
复用现有首次真实输入解锁；sound=off 应关闭全部层。减少动态模式仍保留必要听觉反馈。声音加载失败不得阻止开局，禁止以音乐回调推进战斗或剧情。
长音乐按需加载，当前境域优先，首屏不一次下载全部曲目。保留无损制作母带在 source，运行使用经浏览器验证的压缩格式和必要回退；循环须检查首尾接缝与编码延迟。每项记录来源、商用授权或生成来源、版本、长度、循环点、响度与用途。

## 实施顺序与验收门槛

1. **一段完整试听样片**：标题进入森林，普通敌人战斗一场，包含普通斩击、符箓、全挡、破盾掉血、治疗、胜利、家书阅读。制作 1 条哥特战斗曲、1 条森林底声及上述关键音色。先实际听过，再确定其余素材风格。
2. **混音基础接入**：分组设置、解锁、切场景、暂停/后台、循环与加载失败兜底。验证旧设置迁移、快速切换不重叠，不更改存档规则。
3. **战斗扩充**：接入四类敌人、主角招式、状态与连击变体。用实际结算测试全挡/半挡/掉血、满血治疗、重复点击、敌人死亡中断、连续多击。重点检查重复触发与尾音残留。
4. **全局叙事**：完成剩余音乐、六章环境、关键剧情提示与双结局。剧情略过、日记回看、重复进入结局必须无积压；两个结局都表达完成感。
5. **试听和发布**：耳机、电脑扬声器及至少一台真实手机分别试听；至少连续玩 15 分钟判断疲劳。检查压缩后循环接缝、输出削波、后台静音、长时间声部释放、弱网开局；再跑现有逻辑与音频回归，部署后复测线上资源。

自动化能验证触发、声部、文件与非零信号，不能替代听感验收。每阶段只声明实际完成内容；音色不满意时先调整样片，不把大量同质化合成提示声当作完整配乐交付。
