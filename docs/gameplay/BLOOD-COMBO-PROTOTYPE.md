# 猎血组合试玩原型

2026-10-15。实现了设计提案的第一套样板，尚未作为默认初始牌发布。

本地入口：http://127.0.0.1:8899/?combat=identity

在标题新开猎血：劈砍×2、格挡×2、血契、汲取、割裂、追猎。不要用 debug/auto 参数打开需要保留的试玩进度。读取旧存档仍使用已保存牌组；去掉实验参数也不会删除已经取得的新卡。

- 割裂：1行动力，4伤害；实际扣血且目标存活才挂2回合流血。
- 追猎：1行动力，6伤害；有流血则消耗1回合，基础伤害增加3。消耗发生在伤害前，攻击被格挡仍会消耗。
- 流血：单位回合结束损失2生命，剩余回合减1；重施取较长时间，最多3回合；绕过格挡，不触发攻击事件，不在回合开始递减。
- 卡牌不进普通随机奖励池。复用现有匕首/獠牙插画，状态用三道伤口图形；已添加双语文本。尚无专属新生成动画素材。
