# 守御反击原型

2026-10-15。采用战斗提案中明确列出的通用反击备选方案：不要求额外抽到保留型反攻牌，也不同时叠加两种反击奖励。

本地入口 http://127.0.0.1:8899/?combat=identity ，新开守御。

初始牌：劈砍×2、格挡×2、铁壁、整备、架势、疾刺。普通入口不替换起始牌，旧存档读取实际牌组，新卡不进随机奖励池。

- 整备：1行动力，3格挡，抽1张。
- 架势：1行动力，6格挡；本次敌方行动结束时，至少有一次攻击被格挡，且所有攻击总实际损血为0，获得1反击准备。无攻击、0伤害攻击均不算成功格挡。多段攻击任意一段扣血就失败。持续伤害和付血不计入攻击损血。
- 反击准备：下一玩家回合第一张攻击牌的首次主命中基础伤害+5，然后正常计算虚弱/易伤/格挡等修正。只奖励一次，不让多段攻击每段都+5。符箓与首击遗物独立攻击不消耗。玩家回合结束未使用则清除，最多1层。
- 架势在敌方行动结束清除；反击不会跨战斗存储。
- 界面新增架势/反击准备状态及双语说明，复用盾牌/攻击图标与现有盾牌插画。没有新增专属生成动画。
