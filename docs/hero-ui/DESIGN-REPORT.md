# 主角与战斗 UI 体验调整

2026-10-11。本轮依据用户反馈重新处理角色身份、操作层级与拥挤问题，直接实现到游戏。

## 角色设计

主角为 **提灯旅人**：一位年轻成年女性人类行者，短棕发与一缕浅发、靛蓝斗篷、暗红里衬、青铜护符和暖色提灯构成固定识别点。三个开局传承是同一位旅人的不同打法，进入山海境也保留同一身份，不随背景变成另一位角色。

内置 imagegen 分别生成完整立绘和同身份头像。完整立绘用于首次进入的标题页；存档标题、战斗与行囊使用清楚可辨的人类头像。战斗保持头像布局，避免再塞一张大主角立绘抢占手牌操作区域。缺图时用“旅”字兜底，不再用骷髅代表玩家。

## 操作与视觉层级

核心顺序是 **敌人和意图 → 当前手牌 → 资源与结束回合**。牌组、征途与设置是低频查看操作，收进一个菜单；不再让三个带完整卡框的大按钮抢占敌人名称和意图周围的空间。

| 区域 | 调整 |
| --- | --- |
| 顶部导航 | 一个安静的菜单按钮，152×152 逻辑像素；320 CSS 像素宽度下实际触摸区域超过 44×44 |
| 敌人名 | 去掉厚重整块面板，保留文字、阴影与细分隔线；与意图保持距离 |
| 遗物栏 | 无遗物时不显示占位文字；无妖契最多露出 7 件，有妖契时 4 件；溢出以 +数量汇总，不把全部遗物压成难点的小点 |
| 完整行囊 | 菜单中可打开牌组、征途和遗物/妖契详情；详情每页 4 件，全部图像、中文名称和规则可读，支持翻页 |
| 查看页返回 | 区分“返回行囊”和“返回游戏”，可继续查看其他信息或直接恢复战斗 |
| 行动力/灵韵 | 移除六边宝珠与绕圈小点，改成统一资源刻度牌：上方名称、中央当前/上限、下方剩余刻度；蓝色行动力、金色灵韵 |
| 普通构筑 | 行动力独占左侧资源区，灵韵整组隐藏；避免出现无用的第二个槽 |
| 符箓构筑 | 两种资源并排，共鸣以明确文字显示；0 点资源保留 0/上限及灰色空刻度 |
| 结束回合 | 保留右侧固定拇指操作位置，改为主操作金色样式；危险红色留给返回标题等操作 |

菜单打开会暂停底层战斗时钟。牌组、遗物、征途页都是查看操作，不改牌组、奖励或关卡进度。进入战斗与卡牌实际结算数值未调整。

## 实现边界

主要接入：`src/core/ui-skin.js`、`src/core/ui.js`、`TitleScene.js`、`CombatScene.js`、`JournalScene.js`。头像仍位于 x=240、PLAYER_Y；生命条、侧边盾值、攻击/治疗特效落点保留。底部资源标签与飘字坐标仍使用 STAGE 常量，避免单独挪动导致特效错位。

菜单入口由 `_navButtons.menu` 提供实际位置；回归脚本点击真实按钮，不再依赖旧的 130/360/950、y=260 坐标。旧参考图保留为历史对照，右侧实际截图与新预览展示本轮实现。
