## 叙事语气

- 旅人：第一人称、具体、克制。保留衣料、针、白猫、修屋等生活细节，不改成英雄救世的抽象口号。
- 青禾：母亲本人的意愿必须清楚；她有休息和离开的选择。不可把结局改成主角替母亲决定牺牲。
- 森林之主与守门者：旧约的维护者，语言缓慢或警戒；不额外增加纯邪恶动机。
- 女巫与穷奇：分别使用交易、诱骗语气；不得误译为真的免费奖励或可靠捷径。
- 两种结局都终止强迫献祭。watch 是自主送灯，不是主角接替母亲被囚禁。

## 工程与审校约束

- 翻译不改卡牌、敌人、选项和存档 ID。所有剧情选择按 ID 保存；头像按 speakerId 判断。
- 数字、百分比、费用、状态层数和“本回合/每回合/首次/前两次”逐项核对效果代码。发现文案与规则冲突，记录并明确选择修正文案或调整规则，不能自行猜测。
- 不能在图像内生成必须阅读的文字。当前尚需完成全部纹理的嵌字盘点。
- 英文按词换行，标点不得丢失；完整描述不得省略号截断。自动尺寸检查之后仍需查看实景。
- 扩大 40% 的伪本地化、内嵌字体、繁体地区用语审校仍待完成。
- 引入或修改翻译后运行本地化键/占位符检查，并对受影响页面做真实浏览器验证。连续 18 战路由测试使用调试胜利，只证明衔接，不证明游戏难度或英文阅读体验。
- 英文人工审校至少包含一位理解卡牌规则的使用者，记录歧义、术语一致性、文本可读性和剧情理解；在完成前继续标注预览。
