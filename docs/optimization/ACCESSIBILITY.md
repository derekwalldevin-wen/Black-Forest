# 阅读与无障碍覆盖边界

- 卡牌名称/规则保持不透明，费用不足用费用旁的叉号和文字提示，不再通过整卡压暗传达。双境域、回退材质、费用不足共 48 个实际像素对比度样本达到 4.5:1。
- `applyTheme` 对基础规则框和文字色进行对比度校验；`test-theme-contrast.cjs` 包含低对比度的故障注入。材质覆盖仍由浏览器像素测试验证，单靠色板断言不能证明渲染结果。
- 九张手牌保留 230px 逻辑宽度，选中时两侧让位。H 或“手牌一览”打开原生语义对话框，可调 16–28px 阅读字号。
- 阅读面板包含完整卡牌描述、费用和资源不足说明、生命/行动力/灵韵、当前难度、敌人生命/格挡/意图及我方状态名称与层数。文本提供颜色之外的信息。
- 阅读时暂停战斗，关闭后恢复；选择卡牌只进入查看，不会自动出牌。键盘 H、Escape 和原生按钮焦点有浏览器验证。
- 难度、商店、收藏面板使用原生按钮、单选框、列表及对话框，具有可访问名称。

这不是全流程屏幕阅读器兼容声明。主战斗仍是 Canvas，读牌入口之外的所有操作尚未建立完整语义替代，也未使用实体屏幕阅读器验收。未做全画面色觉模拟认证；当前已验证的是关键信息不只依靠颜色。真机触控与主观阅读体验仍需测试。
