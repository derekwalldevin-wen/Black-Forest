# 事件与遗物声音补充

2026-10-18：新增三个项目原创合成音效，由 `tools/generate-sfx.js` 确定性生成，不包含外部采样。

- `event_enter`：进入事件时的低声木铃和悬疑泛音。浏览器尚未解锁音频时直接跳过，不积压声音。
- `event_choice`：确认普通抉择时的纸页与双音。
- `relic`：成功获得遗物的金属泛音，覆盖战利品及事件。

事件结算优先级为获得遗物、实际回复、实际掉血、普通抉择；一次选择只播放一个结算提示，避免多种结果同时轰鸣。选择防重复闸门位于音效之前。事件进入声与结算提示可能短暂重叠，但受现有八音源上限、音量和静音设置约束。

源文件保留 WAV 用于编辑，游戏清单使用 OGG/AAC。重新生成流程为 `node tools/generate-sfx.js` 后运行 `node tools/optimize-audio.cjs`。压缩工具优先使用 `FFMPEG_PATH`，其次项目临时工具目录，最后系统 PATH；不再依赖已失效的用户临时路径。临时 FFmpeg 不打包。

`EVENT-AUDIO.json` 记录 38 个压缩版本的浏览器实际解码时长、峰值和 RMS，以及实际事件/奖励回调、重复点击与静音结果。解码和响度测量不能替代主观听感；真机扬声器尚未验收。
