# 黑森林 R2 自测候选版 1.1.0-preview.1

日期：2026-10-25。Windows x64。用于先由项目负责人自测，再组织新玩家首次试玩；R2 真人体验验收尚未完成，不是 Steam 或微信正式发行。

新增宽屏卡牌阅读、意图和状态面板，保留中央竖屏战斗；窄窗口保留大字手牌。第一战、第二战与首次奖励提供可跳过、可重看的分步教学。查看、确认出牌、费用不足和取消有明确区分，并修复原生界面穿透与焦点丢失导致的误操作。

本次不改战斗平衡，不默认开启特色初始牌或狼群实验招式。版本仍未签名；只支持已验证的 Windows 键鼠试玩，未声明手柄、Steam Cloud、Steam 成就或微信兼容。

安装包 `.exe` 按向导安装；便携包 `.zip` 完整解压后运行 `Black Forest.exe`。默认资料目录与 R1 相同，请先在游戏标题页导出备份再测试，避免覆盖自己想保留的试玩局。教学可以选择“不再自动提示”，并可从“重看教学”入口打开。

请按 [自测任务](https://github.com/derekwalldevin-wen/Black-Forest/blob/codex/r2-desktop/docs/steam/playtest/R2-PLAYTEST.md) 记录具体卡点。候选包的工程验证、截图和未测项见 [R2报告](https://github.com/derekwalldevin-wen/Black-Forest/blob/codex/r2-desktop/docs/steam/R2-REPORT.md)。

微信版接入调研已准备，但该安装包不是微信小游戏。见 [微信路线](https://github.com/derekwalldevin-wen/Black-Forest/blob/codex/r2-desktop/docs/steam/WECHAT-READINESS.md)。
