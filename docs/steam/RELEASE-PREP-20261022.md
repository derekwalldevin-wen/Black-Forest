# 2026-10-22 打包与 GitHub 发布准备

基线：`codex/r1-desktop`，`9eff11c`。候选版：`1.0.1-preview.1`。

本次在已有 R1 实现上整理可下载的 Windows 预览包与 GitHub 发布资料，不调整战斗数值与默认实验开关。原有两个 R1 提交及证据保留。

## 发布内容

- R1 桌面源码、完整存储与跨端进度迁移实现。
- 构建版本、资源/许可漏项检查、SHA-256 与发布清单。
- 失败能传递到 CI 的检查入口 `node tools/check-release.cjs`。
- GitHub Actions Windows 构建流程。
- 玩家下载/运行说明、版本说明与已知边界。

未跟踪的浏览器资料目录、临时探针、诊断文件和未确认的历史产物不加入提交。安装包与 ZIP 作为 GitHub 预发布附件，不放入 Git 历史。

## 验证记录

初次复测：逻辑 9238/0；本地化、检查点、剧情、收藏、存储后端、跨端迁移与 A/B 自检通过。文件存储及桌面联调在受限沙箱中写失败，沙箱外对同一代码复测分别通过 12 项和 7 项；不将权限限制记作游戏缺陷，也不隐去首次失败。

最终源码、副本、产物和桌面实跑结果在发布完成前追加到本文件。历史报告不作为本次候选包已通过的证明。

## 可复现命令

```powershell
npm ci --prefix desktop
node tools/check-release.cjs
node desktop/build/package.js
node tools/test-desktop-package.js --require-package
```

对最终包运行桌面验收时，可设置 `BLACKFOREST_EVIDENCE_DIR` 保存独立证据目录，以保留原始 R1 记录。不要用只有开发目录才存在的资源补救打包产物缺失。
