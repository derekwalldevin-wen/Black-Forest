# 黑森林微信版：接入与上架路线

日期：2026-10-25。用户已说明有公司或个体工商户；具体执照类型、AppID、出版资质及商业化方式尚未核验。当前交付仍为网页和 Windows 版，尚未完成微信真机适配或提审。

## 目标与首批边界

目标是微信小游戏，可在微信中启动、触屏游玩和保存进度。普通小程序、微信内打开 H5、微信小游戏是不同交付；不把网页链接或桌面 ZIP 称为已上架小游戏。

建议先做受控内部试玩，不先接广告、内购或社交排行。这里是技术范围建议，不代表任何公开运营资质的豁免。现有 GitHub Pages 仅可用作微信内置浏览器的 H5 对照版本，仍需国内网络及手机实测。

## 主体与资料

1. 在微信公众平台按实际主体注册/核对游戏类目，取得对应 AppID；区分有限公司与个体工商户，不预设资质和功能完全相同。
2. 用该主体后台的最新清单核对认证、名称、负责人、联系信息、类目资质及版本提审要求。无需向 Agent 提交微信密码、AppSecret、身份证扫描件或营业执照原件。
3. 准备软件权属材料：软件名称、版本、著作权人、代码和说明书、素材来源与使用授权、自审材料。现有生成记录不是完整的商用授权证明。
4. 核对应用备案、游戏出版审批、运营资质及实名/防沉迷接入要求。应用备案、网站备案和游戏出版物号不是同一手续。有营业执照不等于有出版/运营许可；不声称免费或广告模式自动免审批。
5. 走出版审批路径时，按国家新闻出版署办事指南核对有资质的出版单位、运营机构及著作权证明等条件。是否自营或与发行/运营伙伴合作，需要根据实际主体和平台要求决定。
6. 根据实际数据流填写隐私说明、用户协议和平台要求的声明。首批不主动申请手机号、通讯录、头像或位置；若平台合规功能需要登录与身份验证，采用其要求的接口和流程。

## 四个实施关卡

### W0：准入确认与环境

得到 AppID、确认的主体/类目清单、开发者权限、微信开发者工具。登记已有及待办资料。未取得 AppID 时可做本地准备，不能承诺体验版二维码或公开上架日期。

### W1：最小真机战斗

只做标题、灰狼、初始牌、选牌/出牌/结束回合、音效和本地检查点。验收：安卓+iPhone 各一台，启动→战斗→奖励→关闭重开，控制台无阻断错误；记录首次/再次启动、手机型号、微信版本和实际包体。这一步通过才扩大适配，暂不更换引擎。

### W2：完整游戏与手机体验

接六章十八战、奖励、商店、事件、剧情、教学与多语言。补手机安全区、字号、九张牌、弱网/断网、下载失败、存储失败、切后台/锁屏、热更新与旧档迁移。资源加载允许失败和重试，不能因缓存被清理而误报永久丢档。云存档如需新增，另做账号与冲突设计。

### W3：体验版、审核与公开发布

上传开发版本，按平台流程配置体验成员；用户先自测，再组织不熟悉游戏的玩家。完成所需主体/内容/出版/备案/隐私等材料，按后台清单提审。审核通过并满足运营条件后再决定公开发布。广告和付费单独开阶段，核对安卓/iOS/PC 的当期规则，不照搬 Steam 售价或网页支付。
