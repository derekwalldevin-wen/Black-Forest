# 黑森林：没有署名的家书

## 主线与角色

提灯旅人收到母亲的家书，信的落款却消失了。村里的人还在，但逐渐忘记自己与彼此的名字。旅人带着母亲留下的灯追进黑森林，最终发现森林和青铜之墟之间的旧封印靠吞掉人的记忆维持。母亲青禾曾自愿守灯，却没有获得离开的办法。

故事从寻找一个亲人，推进到理解其他被遗忘的人，再到尊重母亲自己的选择。青禾以灯中的回声出现；结局不凭空让一个肉身恢复，也不要求主角重复她的牺牲。这里的山海异兽参与的是本作原创剧情，不是对古籍事迹的引文。

核心问题：一段曾经保护过人的约定，是否可以因为年代久远，就永远不让人退出？主角的答案来自具体的生活：白猫、屋顶、歌声、银针，而不是一句抽象的救世宣言。

## 六章节奏

| 章 | 发生什么 | 玩家为什么继续 |
|---|---|---|
| 迷雾林缘 | 家书无名、菌群学声、狼王认出灯守护符 | 母亲确实走过这里，村落遭遇的不是普通失踪 |
| 腐沼深处 | 织名人、井底笔记、水面的假母亲 | 分清诱惑与证词，找到通往王座的路 |
| 永夜王座 | 回头路、守门者、森林之主的旧约 | 母亲名叫青禾；树根下还有被掩盖的世界 |
| 青丘之国 | 九种假家、众人的歌、穷奇的捷径 | 不用忘掉其他人来换取团聚，拼回真实生活 |
| 毒泽九首 | 九份残句、传染的遗忘、灰中的新火 | 发现旧约没有出口，但记忆可以彼此支撑 |
| 帝鸿之末 | 永远饥饿的旧约、白泽的提问、无面之舞 | 停止献祭，选择怎样把生活送回世界 |

每一场都有独立标题、明确当下目标、战前遭遇与战后线索；同一敌人再次出现时承担不同的叙事作用。完整 18 战剧本与选择在 `CONTENT.json`，运行权威数据在 `src/core/story.js`。

## 选择与结局

四个明确的选择位于第 3、9、17、18 战之后。

- 第一份证词：记普通人的生活 / 系紧母亲的红线。后续鹿蜀遭遇与尾声回应这个出发点。
- 对灯的承诺：结束永久守灯 / 先护住活人。饕餮遭遇回应这个承诺，最终两种做法都不再接受献祭。
- 怎样记住青禾：生活过的人 / 也曾守夜的人。结局的人物纪念文本变化。
- 怎样送还名字：众灯归乡 / 带灯逐户送还。决定两张不同的结局插画、结局标题、主叙述和结算页。

没有隐藏的正确答案或数值奖励。这些选择改变叙述和结局；现有牌组、敌人能力与平衡不随剧情改动。两种结局分别解决“结束旧约”和“保留互通的路”，主角都可以休息或回家，而不是再次被困成燃料。

## 阅读体验与美术

普通遭遇两页战前、两页战后，每页一个说话者，一段短对白。重要决定另有选择与即时回应。阅读由玩家推进，不自动翻页；可略过普通段落。遇到决定，“直达选择”只跳过前文，不能替玩家作答。结局可完整阅读，也可以略过。

采用大幅 3:2 场景插画、独立中文对白面板、当前目标/新增线索、页码与底部拇指按钮。正文 44 逻辑像素，按钮高 152，在 320 宽度下仍超过 44 CSS 像素。图片保持 3:2，不把主角脸拉宽。中文由游戏字体绘制，生成图不承担文字。

新增六章场景及两张结局插画。共同识别点为靛蓝斗篷、暗红里衬、青铜护符、暖色提灯和红线。黑森林使用冷靛蓝、苔色、旧木与水彩；青铜之墟使用赭金、青玉、朱砂与墨。母亲的声音以灯为视觉载体，避免凭空增加一个与叙述不符的实体人物。

原图在 `docs/story/source/`，运行 WebP 在 `assets/story/`。`PROMPTS.json` 保存内置 imagegen 的全部提示词及原始路径，`ASSETS.json` 保存尺寸、体积和哈希。技术转码工具 `tools/prepare-story-art.js`；原图不进运行包。

## 接入与存档

`StoryScene` 位于战斗和战利品之间；战前剧情集中在 Combat 入口拦截，不漏掉标题续玩、事件返回或章节转换。剧情读完才进入实际战斗，不在阅读时偷跑敌人回合。

`RUN.story` 记录已读段落、四个选择与待续接的战后/奖励状态，列入存档白名单。新游戏清空；旧档缺字段时显式初始化，不继承上一局选择，不改旧牌组、生命或金币。旧档从中段进入时补一页当前章节摘要，随后继续当前遭遇。

胜利已支付时写入剧情续接标记。重新进入游戏可恢复战后阅读或奖励页；候选卡牌/遗物、已领取物品与当前奖励阶段一同保存，不能靠重载重复领取。推进关卡时清理标记，避免重复战斗和重复支付。剧情手记只开放已经历段落，回看不改选择、不发奖励。在行囊中回看保留战斗暂停；结局页也能回看整段旅途。

调试默认略过剧情以便原有战斗工具工作；用 `?debug=1&auto=1&story=on` 明确开启剧情验收。正式游玩默认开启；`?story=off` 可作不阅读剧情的对照。
