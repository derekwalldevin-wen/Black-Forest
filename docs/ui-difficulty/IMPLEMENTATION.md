# 难度选择界面改版

日期：2026-10-25。范围：先用内置 image_gen 生成美术稿，再生成生产用插画，接入当前本地游戏。

## 视觉与交互

- 哥特森林背景、羊皮纸面板、暗金边框；三张选择面板使用新生成的提灯、长剑和荆棘晶石插画。
- 生命上限、普通战后回复、精英 / BOSS 战后回复分区显示；选中边框与勾号同时提示选择。
- 所有功能文字均为真实 DOM 文本，保留中英文；图片只承担装饰。数值直接读取 `RUN_DIFFICULTIES`，没有调整平衡。
- 默认标准难度，原生单选框提供方向键切换；Tab 到开始与返回，Esc 取消。取消保留传承选择并恢复标题场景；重复确认只建立一次新局。
- 720p 桌面同时显示三档；小屏可滚动选择，底部开始与返回常驻，矮屏显示滚动提示。

## 验证

`node tools/verify-difficulty.cjs` 使用独立临时 HTTP 端口与新浏览器资料，不修改玩家存档。中英文分别覆盖 320 × 568、390 × 844、768 × 1024、1280 × 720、1366 × 768；实际选择、建局、保存与载入覆盖三档共六组。另检查方向键、空格不穿透、Esc 取消、重复弹窗与确认只执行一次。后续复核定位到快速关闭弹窗时暂停队列未恢复的真实问题，已成对恢复暂停，并增加连续三次同帧开关后跨三帧的检查。键盘开局继续验证到首次教学暂停战斗、关闭教学恢复战斗。证据在 `evidence/` 与 `docs/bugs/play-controls/`。

逻辑回归：9238 passed / 0 failed；卡牌本地化：43 张通过。运行资产收集：全部存在，无无法解析的引用。最终结果以 `evidence/verification.json` 为准。浏览器尺寸与触摸模拟不等同于实体手机验收。
