# 难度选择原稿还原 · 2026-10-26

依据 `../concept-v1.webp` 接入本局难度选择界面。美术稿保留为原稿；`../index.html` 提供本轮/上一版、中英文与五种屏幕实景切换。

## 本轮实现

- 以 `image_gen.imagegen` 从原稿生成提灯与雕花标题牌匾、森林城堡背景、藤叶羊皮纸外框，以及提灯/长剑白花/荆棘晶石三个完整选项面板。金色主按钮、靛蓝次级按钮和分隔花饰复用上一轮已生成的同风格组件。
- 选中选项保留金色描边、光晕与圆形勾选标记。标准难度保留推荐签；默认标准，原生 radio 支持方向键与触控。键盘焦点沿面板内部显示。
- 所有标题、说明、生命值、回复比例都由真实字体与 RUN_DIFFICULTIES 绘制。保留故事 90 HP / 32% / 48%、标准 70 HP / 26% / 42%、挑战 60 HP / 20% / 34%，不改玩法数值。
- 标题与底部操作固定，中间选项独立滚动；只在实际溢出时显示滑动提示。英文长文与 320 像素窄屏允许滚动，开始/返回按钮保持可见，按钮至少 44 CSS px 高。
- 底部深色衬底只覆盖按钮区，滑动提示和回复说明仍位于浅纸区域。取消、同帧开关、重复确认、Title 暂停/恢复和首次教学衔接保持原有行为。

## 素材与来源

运行资源在 `assets/ui/difficulty/`，共 6 张 WebP、1,371,182 字节（约 1.31 MiB）。原始生成文件、完整提示词、参考角色、尺寸、哈希和裁切信息见 `SOURCES.json`。原始 PNG 另保存在 `source/`，不进入运行包。可用 `node tools/prep-difficulty-ui-v2.cjs` 复现透明边界裁切、缩放及编码；脚本没有重画插画。

两份合并选项图的实际比例不适合逐行接入，已保留为 superseded 来源，最终采用三张单独面板。一项双参考图编辑长时间未返回，终止后改为单参考重新生成；未返回的调用没有作为素材使用。全部最终生产素材均已成功返回并接入。

来源记录已接入 `tools/audit-asset-rights.cjs` 及 Steam 权利台账；这是生成与引用记录，不代表已完成发行主体的权利确认。
