# 沉浸式宽屏 · 2026-10-29

宽屏由独立信息栏改为游戏环境的延展。中央仍是原有 9:16 战场，两侧使用匹配境域的完整森林/山海水彩场景，旅人和当前对手的正式立绘融入环境。保留简短意图与来袭/格挡提示，移除默认展开的手牌目录、状态说明、资源表和查看教学文案。

选牌时，右侧才出现真实卡牌插画、当前费用、规则与明确的打出/收回按钮；收回或出牌后恢复遭遇立绘。详细手牌改为可展开的插画卡袋，持续状态和按键收进独立工具，默认关闭。大字读牌 H、行囊和主动查看旅人手册仍可用，首次遭遇教学保留。窄屏的卡牌与手势没有重做。

## 美术与接入

内置 `image_gen.imagegen` 生成黑森林与山海两张 16:9 场景，保持月夜提灯、古堡，以及云山、青铜、朱砂的既有视觉语言。运行 WebP 在 `assets/ui/immersive/`；完整提示词、参考图、源图路径、哈希与大小见 `SOURCES.json`。纸框复用已生成素材，只裁去图集底部余片，不用程序重画。旅人、对手与卡牌图继续使用正式素材。

实现中修正了两个接入问题：Phaser 载入后会释放 blob URL，DOM 插画现在读取正式素材地址及优化映射；共用纸框的图集余片不适合做竖向卡牌，已机械裁切完整边框，避免规则文字压到装饰线上。资源收集器与来源台账已识别新增三个运行文件。
