# 功能界面美术整合 · 2026-10-25

已将商店、手牌阅读、教学、收藏成就、进度迁移五类原生功能界面改为统一的插画界面，新增运行素材已进入资源收集清单。查看 `index.html` 可对照 AI 概念与游戏截图。

## 排查与实施

难度选择已有 AI 美术，保留其独立布局。标题、战斗、奖励、事件、剧情、征途/暂停使用现有游戏画布美术，本次未重复替换。开发用文档页不是玩家界面。

## 素材与实现

使用内置 `image_gen.imagegen`，保存商店概念稿、四界面设计板和四份实际运行素材。透明徽章图集为三列两行，边框保留 alpha，纸张与商店横幅为不透明 WebP。提示词、输入参考角色、原图路径、尺寸、字节数和 SHA-256 见 `SOURCES.json`。原始 PNG 另存 `source/`，该目录按项目约定不进入运行包。初次补充设计板任务长时间未返回，停止后用简化提示重试成功；运行素材四项均成功生成。

`src/core/painted-ui.js` 管理框架、素材地址、境域按钮材质和弹窗暂停/恢复；`assets/painted-ui.css` 管理自适应布局。中间内容可滚动，底部操作固定；超出窗口时显示继续滚动提示。文字、卡名、金币、成就与规则均由真实数据绘制，概念图中的示例文案不进入规则。

素材地址经过 `ASSET_VARIANTS` 和 `document.baseURI`，可适应网页根目录、GitHub Pages 子目录及桌面资源收集。商品限购、删牌下限、费用、教学进度、收藏与存档校验保持原规则。收藏/商店/迁移统一配对排队中的 pause/resume，避免同一帧关闭导致场景一直暂停。

## 验证

`tools/verify-painted-ui.cjs` 在独立 Edge 用户环境运行，采集中文/英文 × 手机/桌面/320×568 小屏 × 五界面，并验证东方商店与子目录路径。检查范围包括视口、滚动区与固定底栏、九张手牌 28px 阅读、费用不足查看不消费、教学输入隔离与翻页、真实 JSON 下载、购买/删牌限次、金币不足、五张牌下限、Esc 与同帧关闭恢复。

桌面导入的确认、取消、应用及错误提示以隔离 bridge stub 验证；这不是原生 OS 文件选择器测试。没有接触玩家真实存档，也不声称完成微信或手机真机验收。最终截图、检查数量、网络/页面错误记录见 `verification.json`。
