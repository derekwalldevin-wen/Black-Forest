# 插画 UI 原稿还原 · 2026-10-25

本轮以 `../shop-concept-v1.webp` 与 `../utility-concepts-v1.webp` 为视觉依据，重新生成并接入可用的生产组件。目标是恢复原稿的插画、层次、装饰密度与材质关系。预览页 `../index.html` 提供原稿/实装并排，以及上一版/本轮切换。

设计稿中的示例数值和卡牌规则没有写进美术。所有标题、描述、资源、价格、费用、进度仍由游戏真实数据与字体绘制。可支付的卡牌保留彩色插画，费用不足的卡牌使用灰色，仍可阅读与选中。

## 资源交付

使用内置 `image_gen.imagegen`，以已批准稿为参考生成。运行文件在 `assets/ui/native/`，逐文件尺寸、字节数、SHA-256、原始图路径、提示词、参考角色及切片来源见 `SOURCES.json`。生产切片只执行网格裁切、透明边界裁切、缩放和 WebP 编码；未用代码重画插画。可通过 `node tools/prep-native-ui-v2.cjs` 复现切片。

初次并行插画任务长时间未返回，停止后改为逐张生成，所有所需素材已成功返回并保存。透明度修整也走内置生图工具；没有切换到 CLI/API。原始 PNG 另存在 `source/`，不进入运行包。

## 布局与交互验收

`tools/verify-painted-ui.cjs` 采集 33 个真实界面案例，覆盖中英文 × 390×844、1280×720、320×568 × 五类界面，以及东方商店、导入错误和 GitHub Pages 子路径。验证正文无横向溢出、底部操作留在窗口、28px 九张手牌可滚动阅读、购买/删牌限次、金币不足、五张牌下限、导出下载、导入确认/取消/拒绝、教学隔离和弹窗暂停恢复。完整记录见 `verification.json`。

另外运行出牌确认/指针中断/触屏回归、R2 八组输入/教学回归、9238 条逻辑断言、迁移格式、收藏与商店经济测试。实景中发现并修复了两项美术接入问题：旧教学样式重置背景尺寸导致金色按钮被裁切；桌面边框增加占位导致最小窗口手牌区域被挤压。最终使用透明藤叶四角，清除了初稿纸张角片的矩形接缝。

本轮是自适应的可交互还原，不把概念图整体当作 UI 贴图；窄屏、英文长文和大字号会滚动。原稿里假设的存档路径、示例牌组和成就规则不会成为游戏功能。桌面导入确认界面使用隔离 bridge stub 验证，不能据此宣称测过原生 OS 文件选择器；微信与手机真机也不在本轮验收范围。
