# UI 文案与实际行为差异

本轮参考图按当前实际效果设计，数值与运行效果保留现有实现。以下差异应在 UI 实施时校正文案；如果希望改变玩法，需要另作设计决策。

1. **升契**：events.js 的选项描述写从三张牌中选一张，但 effects 是 ascend 加 card。EventScene.pick 只为删牌启动选牌界面；card 算子直接随机取得一张牌。因此当前流程是升契并随机获得一张牌。新版参考图采用实际行为。没有可升阶妖契也仍可获得随机牌，不能把整个选项禁用。

2. **铸坊淬火**：选项描述写罕见牌，效果指定 rarity: rare，对应当前牌库的稀有档。新版参考图写七十金币获得一张稀有牌。熔铸的旧牌也是随机移除，不是玩家选择丢弃；新版文案直接写随机换牌。

3. **早期参考图**：凝神真实费用为一点行动力、抽两张；血契真实费用为零、失去三点生命并抽两张；疾刺是一点费用、四点伤害并抽一张。新版图使用这些规则，不能使用旧图中的八伤、血契攻击等虚构数值。
