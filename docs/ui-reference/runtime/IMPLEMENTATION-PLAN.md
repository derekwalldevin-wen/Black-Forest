# 全套参考图接入计划

原目标：46项参考稿落到可操作游戏，包含此前建议新增的牌组浏览、暂停设置、线性征途进度。保留实际规则与数值，以真正的卡牌与按钮替代整屏图片。

1. 制作两境域的可拉伸界面皮肤：主按钮、次按钮、危险按钮、宣纸、深色面板，加玩家头像与蓝盾。保存原图、切割坐标、提示词及运行贴图。
2. 建立共享材质与文字组件，接入标题、传承、帮助、确认和真实加载进度。
3. 战斗统一生命条、侧盾、意图与资源图标；选中态提供大号完整规则；保留已实现的出牌保护、敌人动态及蓝/红/绿反馈。
4. 奖励三选一、遗物二选一、领取总结、事件18项、结果与删牌逐项接入，并验收真实流程。
5. 实现牌组筛选与详情、冻结底层场景的暂停设置、只读六章十八战进度。设置持久化；返回标题说明战斗重打。
6. 以SCREENS.json的46项建立运行时截图与交互证据；在390宽和更窄视口检查阅读、触摸、裁切和遮挡，跑逻辑及卡牌/动态回归。

完成前不能仅以贴图加载或逻辑测试通过判定整套完成。每项仍需运行时显示与实际操作证据。
