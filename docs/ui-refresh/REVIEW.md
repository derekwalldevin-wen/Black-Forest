# 行动力与菜单美术更新

采用内置 image_gen 生成一轮六图标透明素材，完整提示词保存在 PROMPTS.json。原图在 source/icons-v1.png（本地留存，不随发布上传）；生产 PNG 在 assets/ui/refined-*-v1.png。

## 美术取舍

- 行动力采用蓝玻璃提灯和闪电，灵韵采用琥珀火焰与青铜坠饰；图形和颜色同时区分资源。
- 数字不嵌入生图。实时数量、资源名称、余量刻度由代码绘制；资源耗尽时图标变暗。
- 行囊、牌组、地图、书册统一深靛蓝与旧黄铜材质。菜单四个主要入口配图，设置和退出按钮保留文字层级。
- 保留菜单 152 逻辑像素点击区域和现有暂停行为；不改变任何资源规则或数值。

## 实景审核

已逐张查看 390 宽菜单、山海战斗与 320 宽山海战斗截图。图标轮廓明确，数字与插画分区，无文字压在插画上。两境域沿用统一资源色彩避免认知切换。

`node tools/verify-ui-refresh.js` 通过六张图的透明边缘、16 组资源状态（0/1/3/4，320/390，两境域）、资源与数字不重叠、真实菜单点击、四个图文入口检查。证据见 REPORT.json 和同目录八张实景 PNG。

`node tools/verify-hero-ui.js` 通过菜单、牌组、征途、遗物分页、暂停时钟及资源耗尽回归。`node tools/test-logic.js` 为 9127 passed / 0 failed。

浏览器视口检查不代表已完成真机性能测试。
